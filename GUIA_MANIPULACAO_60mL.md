## ETAPA 1: PREPARAÇÃO DOS ETOSSOMAS (30 minutos)

Esta é a etapa mais crítica - os etossomas são o sistema de penetração.

### Passo 1.1 - Base Etossomal
```
┌─────────────────────────────────────────────────────────────┐
│ BÉQUER 250mL - AQUECIMENTO                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. Adicionar ao béquer:                                    │
│     • Etanol 96° ...................... 18,0 mL             │
│     • Lecitina de Soja ................ 1,8 g               │
│                                                             │
│  2. Aquecer a 40°C sob agitação magnética                   │
│                                                             │
│  3. Aguardar dissolução completa da lecitina (5-10 min)     │
│     → Solução deve ficar TRANSLÚCIDA                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Passo 1.2 - Adição dos Potencializadores
```
┌─────────────────────────────────────────────────────────────┐
│ MANTER A 40°C SOB AGITAÇÃO                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  4. Adicionar LENTAMENTE (gota a gota):                     │
│     • Transcutol® ..................... 6,0 g               │
│       (adicionar em ~2 minutos)                             │
│                                                             │
│  5. Adicionar:                                              │
│     • Propilenoglicol ................. 6,0 mL              │
│       (adicionar em ~1 minuto)                              │
│                                                             │
│  6. Manter agitação por 5 minutos                           │
│                                                             │
│  7. Adicionar:                                              │
│     • Polissorbato 80 ................. 0,6 g               │
│     • Ácido Oleico .................... 1,8 g               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Passo 1.3 - Formação das Vesículas
```
┌─────────────────────────────────────────────────────────────┐
│ HOMOGENEIZAÇÃO - CRÍTICO!                                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  8. HOMOGENEIZAR em alta velocidade:                        │
│     • Velocidade: máxima (>10.000 rpm se possível)          │
│     • Tempo: 5 minutos contínuos                            │
│                                                             │
│     → A mistura deve ficar OPALESCENTE/LEITOSA              │
│     → Isso indica formação das vesículas                    │
│                                                             │
│  9. Se disponível banho ultrassônico:                       │
│     • Submeter por 10 minutos                               │
│     • Reduz tamanho das vesículas (melhor penetração)       │
│                                                             │
│  10. Adicionar sob agitação:                                │
│      • Mentol ......................... 0,6 g               │
│      (sensação refrescante + penetração)                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**VERIFICAÇÃO:** Aspecto opalescente/leitoso, sem grumos, sem separação.

## PROBLEMAS COMUNS E SOLUÇÕES

### 1. Lecitina não dissolve
**Solução:** Aumentar temperatura para 45°C, agitar mais tempo

### 2. Espironolactona não dissolve
**Solução:** Aumentar agitação, dar mais tempo (5-10 min)

### 3. Separação de fases
**Solução:** Homogeneizar novamente em alta velocidade

### 4. pH não estabiliza
**Solução:** Adicionar NaOH/ácido muito lentamente, gota a gota

### 5. Aspecto muito líquido
**Solução:** Normal para sistema etossomal - é sérum, não creme

### 6. Odor forte
**Solução:** Adicionar 2-3 gotas de óleo essencial de menta

## MODO DE USO DO PRODUTO FINAL

1. **Agitar bem** antes de cada uso
2. Aplicar **1 mL** no couro cabeludo limpo e seco
3. Massagear por **2-3 minutos**
4. **Não enxaguar**
5. Usar **1-2x ao dia** (preferência noturna)
6. O frasco de 60mL dura **~30-60 dias**
